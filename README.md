# ПР1. Ответы на контрольные вопросы

1. В С# ошибки обнаруживаются при компиляции до запуска программы в питоне же ошибки заметны только посл выполнения програмы

2. Команда dotnet состоит из двух шагов это сборка проекта и запуска приложения

3. Папка bin/ нужна для содержания готовых сборок такие как dll и exe. Папка obj/ содержит в себе промежуточные файлы.Не нужно хранить в гит потому что когда мы напишем команду dotnet run они создатутся заново

4. Commit сохраняет состояние файла в определеный момент в истории репозитория. Push это команда которая загружает локальные комиты в удаленый репозиторий 

5. Конкатенация обьединяет переменые вручну, а Интерполяция позволяет вставить значения прямо в строку. Мне удобнее использовать Интерполяцию потому что это легче и удобнее, и не путаешься в написании кода.

6. Если целочисленые переменые разделить друг на друга то получится целое число, чтобы получилось дробное надо хотябы чтобы одна переменная была дробной(double)

7. const это константа у которой нельзя поменять значение после того как мы обьявили её. У обычной переменной мы можем поменять значение в любой момент. Const нужно использовать для значений которые не должны изменяться, пример как дни в неделе.
